# Product Management Skill

**Purpose:**
Provide capabilities for converting ideas into well-defined products and managing their development.

**Knowledge Area:**
- PRDs (Product Requirements Documents)
- User stories
- Feature prioritization
- Roadmapping

**When to Use:**
Use this skill when defining the scope, requirements, user stories, and feature roadmaps for a new product.

**Expected Outputs:**
- Product Requirements Documents (PRDs)
- User story backlogs
- Prioritized feature lists
- Product roadmaps
